# 배너 원격 설정

앱 하단 배너는 좌우 **두 칸**으로 나뉜다. 칸 수·문구·색·로고·링크는 이 JSON 하나가 정한다.
**파일만 고치면 앱을 새로 배포하지 않아도 바뀐다.**

## 어디에 있나

정본은 GitHub에 있고, 앱은 이 주소를 먼저 본다.

```
https://raw.githubusercontent.com/lodong-co/app-config/main/lodong-viewer/banner.json
```

여기가 죽으면 `https://egghosting.com/app/lodong-viewer/banner.json` 를 대신 본다(있을 경우).
둘 다 안 되면 마지막으로 받아 둔 값, 그것도 없으면 앱 내장 기본값으로 나온다.

🔴 **raw.githubusercontent.com 은 약 5분간 캐싱한다.** 커밋 직후 바로 반영되지 않는다.
급히 확인할 때는 GitHub 웹에서 파일 내용을 보거나 주소 뒤에 `?cb=아무값` 을 붙여 확인할 것.

## 반영 시점

- 앱을 켤 때 확인하고, 마지막 확인으로부터 `refreshHours` 시간이 지났을 때만 다시 받는다(기본 6시간).
- 급히 전체에 반영해야 하면 `refreshHours` 를 1로 낮춰 두었다가 나중에 되돌린다.
- **화면은 항상 캐시된 값으로 즉시 그린다.** 서버가 죽어도, 인터넷이 안 돼도 배너는 이전 값으로 나온다.
- JSON 문법이 깨졌거나 값이 이상하면 조용히 무시하고 이전 값을 유지한다. 배너 때문에 앱이 멈추지 않는다.

## 항목

| 키 | 뜻 |
|---|---|
| `enabled` | `false` 면 배너를 아예 숨긴다 |
| `refreshHours` | 다시 확인하는 간격(시간), 1~168 |
| `slots` | 배너 칸. **최대 2개**. 1개면 통으로, 2개면 좌우 반씩 |
| `light` | 앱이 **밝은** 테마일 때 쓸 색 |
| `dark` | 앱이 **야간** 테마일 때 쓸 색 |
| `configUrl` | 설정을 다른 서버로 옮길 때. 앱이 다음부터 그쪽을 먼저 본다(https 만) |

`slots` 안쪽:

| 키 | 뜻 |
|---|---|
| `title` | 윗줄(작은 글씨, 강조색) |
| `subtitle` | 아랫줄(굵은 글씨) |
| `link` | 누르면 갈 곳. `https://...` 는 브라우저, **`tel:...` 는 전화 걸기 화면** |
| `showLogo` | 오른쪽에 로고를 붙일지 |
| `logo` | 로고 이미지 주소. **비워 두면 앱에 들어 있는 에그호스팅 로고**를 쓴다 |

`light` / `dark` 안쪽:

| 키 | 뜻 |
|---|---|
| `bg` | 배너 배경색 `#RRGGBB` 또는 `#AARRGGBB` |
| `fg` | 아랫줄 글자색 |
| `accent` | 윗줄 글자색 |

빠진 키는 기본값을 그대로 쓴다. 문구만 바꾸고 싶으면 `title`/`subtitle` 만 넣어도 된다.

## 주의

- **두 칸으로 나누면 글자 자리가 반으로 준다.** 윗줄 9자, 아랫줄 8자 정도가 한계고 넘으면 뒤가 잘린다.
  (`대한민국 대표 호스팅` 이 잘려서 `한국대표 호스팅` 으로 줄인 전례가 있다)
- 배경이 어두우면 로고도 밝은 판을 써야 한다. 검정 로고를 어두운 배경에 올리면 보이지 않는다.
- 로고는 **가로로 긴 투명 PNG**. 두 칸일 때 높이 20dp로 그려진다. 2MB를 넘으면 무시한다.
- 전화번호는 바로 걸지 않고 다이얼러에 넣어 준다(통화 권한 불필요, 사용자가 한 번 더 확인).
- 앱이 서버로 보내는 건 이 파일 요청뿐이다. 기기 정보나 문서 내용은 일절 보내지 않는다.

## 바꾼 뒤 확인

```bash
python -m json.tool lodong-viewer/banner.json      # 올리기 전 문법 확인
curl -s "https://raw.githubusercontent.com/lodong-co/app-config/main/lodong-viewer/banner.json?cb=$RANDOM"
```
