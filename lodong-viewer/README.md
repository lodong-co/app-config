# 배너 원격 설정

앱 하단 배너의 문구·색·로고·링크는 이 JSON 하나가 정한다.
**파일만 고치면 앱을 새로 배포하지 않아도 바뀐다.**

## 올릴 위치

```
https://egghosting.com/app/lodong-viewer/banner.json
```

앱에 박혀 있는 주소는 `BannerStore.CONFIG_URL` 한 곳뿐이다. 주소를 옮기려면 그때는 앱 배포가 필요하니
경로를 먼저 확정할 것.

## 반영 시점

- 앱을 켤 때 확인하고, 마지막 확인으로부터 `refreshHours` 시간이 지났을 때만 다시 받는다(기본 6시간).
- 급히 전체에 반영해야 하면 `refreshHours` 를 1로 낮춰 두었다가 나중에 되돌린다.
- **화면은 항상 캐시된 값으로 즉시 그린다.** 서버가 죽어도, 인터넷이 안 돼도 배너는 이전 값으로 나온다.
- 값이 잘못됐거나 파일이 없으면 앱에 들어 있는 기본값으로 돌아간다. 배너 때문에 앱이 멈추지 않는다.

## 항목

| 키 | 뜻 |
|---|---|
| `enabled` | `false` 면 배너를 아예 숨긴다 |
| `title` | 윗줄(작은 글씨) |
| `subtitle` | 아랫줄(굵은 글씨) |
| `linkUrl` | 눌렀을 때 열 주소 |
| `refreshHours` | 다시 확인하는 간격(시간), 1~168 |
| `light` | 앱이 **밝은** 테마일 때 쓸 색·로고 |
| `dark` | 앱이 **야간** 테마일 때 쓸 색·로고 |

`light` / `dark` 안쪽:

| 키 | 뜻 |
|---|---|
| `bg` | 배너 배경색 `#RRGGBB` 또는 `#AARRGGBB` |
| `fg` | 아랫줄 글자색 |
| `accent` | 윗줄 글자색 |
| `logo` | 오른쪽 로고 이미지 주소. **비워 두면 앱에 들어 있는 에그호스팅 로고**를 쓴다 |

빠진 키는 기본값을 그대로 쓴다. 그래서 문구만 바꾸고 싶으면 `title`/`subtitle` 만 넣어도 된다.

## 주의

- 배경이 어두우면 로고도 밝은 판을 써야 한다. 검정 로고를 어두운 배경에 올리면 보이지 않는다.
- 로고는 **가로로 긴 투명 PNG**가 맞다. 화면에서는 높이 28dp로 그려진다. 2MB를 넘으면 무시한다.
- 한 줄씩만 나온다. 문구가 길면 뒤가 잘린다(윗줄 ~20자, 아랫줄 ~12자 권장).
- 앱이 서버로 보내는 건 이 파일 요청뿐이다. 기기 정보나 문서 내용은 일절 보내지 않는다.

## 바꾼 뒤 확인

```bash
curl -s https://egghosting.com/app/lodong-viewer/banner.json | python -m json.tool
```

JSON 문법이 깨지면 앱은 그냥 이전 값을 유지한다(조용히 무시). 올리기 전에 위 명령으로 한 번 확인할 것.
